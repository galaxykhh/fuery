# Public API the documentation deliberately leaves unnamed, with the reason.
# One entry per line, `name: reason`. A trailing * matches any ending, so
# `*.subscribe` covers every type's subscribe.
#
# Only list something here when an app author never has to name it. Everything
# else belongs in the report as work to do.

# Subscribable plumbing. Apps listen through `stream`, or mount a widget.
*.subscribe: apps listen through stream or a widget
*.onSubscribe: called by Subscribable when a listener arrives
*.onUnsubscribe: called by Subscribable when the last listener leaves
*.hasListeners: internal bookkeeping
*.listeners: internal bookkeeping
*.clearListeners: called by QueryObserver.destroy

# Called by the package itself.
*.getOptimisticResult: the widgets call this to paint the first frame
QueryClient.mount: assigning Fuery.client mounts the client
QueryClient.unmount: assigning Fuery.client unmounts the old client
NotifyManager.schedule: the package schedules its own notifications
FocusManager.onFocus: called by FueryBinding

# Callback shapes. Readers write closures; the docs show each shape inline.
QueryFn: the docs show the closure instead
InfiniteQueryFn: the docs show the closure instead
MutationFn: the docs show the closure instead
GetNextPageParam: the docs show the closure instead
GetPreviousPageParam: the docs show the closure instead
PlaceholderDataFn: the docs show the closure instead
MutationOnMutate: the docs show the callback instead
MutationOnSuccess: the docs show the callback instead
MutationOnError: the docs show the callback instead
MutationOnSettled: the docs show the callback instead
ResultCondition: the type of buildWhen and listenWhen, written inline
ResultWidgetBuilder: the type of builder, written inline
ResultWidgetListener: the type of listener, written inline
RetryDelay: the type of retryDelay, written inline
FocusSetup: the return type of setEventListener, written inline
OnlineSetup: the return type of setEventListener, written inline

# Singletons apps use, classes they don't name.
FocusManager: apps use the focusManager singleton
OnlineManager: apps use the onlineManager singleton
NotifyManager: apps use the notifyManager singleton

# Cancellation internals.
AbortController: Fuery owns the controller; a query function gets the signal
AbortSignal.reason: throwIfAborted throws it, so apps meet it as the error
QueryObserver.currentQuery: the observer attaches itself; apps read results

# Deprecated names for the definitions.
QueryOptions: deprecated name of Query
InfiniteQueryOptions: deprecated name of InfiniteQuery
MutationOptions: deprecated name of Mutation
AnyMutationOptions: deprecated name of AnyMutation
infiniteQueryOptions: deprecated, use the InfiniteQuery constructor

# Names a key or a hash never needs.
QueryKey: a key is a plain list
MutationKey: a key is a plain list
hashKey: the package hashes keys itself
replaceEqualDeep: documented as behaviour, in Selecting part of the state
defaultRetryDelay: the default is described in the options table
